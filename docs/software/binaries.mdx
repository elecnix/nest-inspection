# Software Binaries

The Nest Learning Thermostat firmware contains numerous executable binaries that provide system functionality, user interfaces, and specialized services. This document catalogs the key binaries and their purposes.

## System Binaries

### Essential System Programs
- **/bin/sh**: POSIX shell interpreter
- **/bin/bash**: Enhanced Bourne shell
- **/bin/busybox**: Multi-call binary for Unix utilities
- **/bin/systemctl**: Systemd service manager
- **/bin/journalctl**: Systemd journal viewer
- **/bin/dbus-send**: D-Bus message sending utility
- **/bin/dbus-monitor**: D-Bus message monitoring tool

### Core Utilities
```bash
# BusyBox applets (examples)
/bin/ls           # List directory contents
/bin/cp           # Copy files
/bin/mv           # Move/rename files
/bin/rm           # Remove files
/bin/cat          # Concatenate files
/bin/echo         # Display messages
/bin/sleep        # Delay execution
/bin/kill         # Send signals to processes
/bin/ps           # Process status
/bin/top          # Process viewer
```

## Nest-Specific Binaries

### nlclient
- **Path**: `/nestlabs/bin/nlclient`
- **Size**: ~4.9MB
- **Purpose**: Main user interface application
- **Dependencies**: GTK+, D-Bus, hardware libraries
- **Features**: Touch interface, temperature display, settings

#### nlclient Command Line Options
```bash
# nlclient usage
/nestlabs/bin/nlclient [options]

Options:
  --display=<device>     Display device (default: /dev/fb0)
  --touch=<device>       Touch device (default: /dev/input/event0)
  --config=<path>        Configuration directory
  --log-level=<level>    Logging level (debug,info,warn,error)
  --debug-mode           Enable debug mode
  --no-animations        Disable UI animations
```

### thermostat-manager
- **Path**: `/nestlabs/bin/thermostat-manager`
- **Size**: ~2.1MB
- **Purpose**: Core thermostat control logic
- **Features**: Temperature control, learning algorithms
- **Interface**: D-Bus API for control services

### sensor-service
- **Path**: `/nestlabs/bin/sensor-service`
- **Size**: ~800KB
- **Purpose**: Hardware sensor management
- **Sensors**: Temperature, humidity, motion, light
- **Features**: Calibration, filtering, data aggregation

### network-service
- **Path**: `/nestlabs/bin/network-service`
- **Size**: ~1.2MB
- **Purpose**: Network connectivity management
- **Features**: Wi-Fi, Weave, cloud connectivity
- **Integration**: ConnMan integration

### update-service
- **Path**: `/nestlabs/bin/update-service`
- **Size**: ~1.5MB
- **Purpose**: Over-the-air update management
- **Features**: Update download, verification, installation
- **Security**: Signed update verification

## Hardware Interface Binaries

### gpio-tool
- **Path**: `/nestlabs/bin/gpio-tool`
- **Purpose**: GPIO pin configuration and testing
- **Usage**: Hardware debugging and configuration

```bash
# gpio-tool examples
gpio-tool --list                    # List GPIO pins
gpio-tool --set <pin> <value>      # Set GPIO pin value
gpio-tool --get <pin>              # Get GPIO pin value
gpio-tool --direction <pin> <dir>  # Set pin direction
```

### i2c-tool
- **Path**: `/nestlabs/bin/i2c-tool`
- **Purpose**: I2C bus communication and debugging
- **Features**: I2C device scanning, read/write operations

```bash
# i2c-tool examples
i2c-tool --scan                    # Scan I2C bus
i2c-tool --read <bus> <addr> <reg> # Read from I2C device
i2c-tool --write <bus> <addr> <reg> <data> # Write to I2C device
```

### spi-tool
- **Path**: `/nestlabs/bin/spi-tool`
- **Purpose**: SPI bus communication and testing
- **Features**: SPI device communication, diagnostics
