# Thermostat Data

The Nest Learning Thermostat maintains extensive operational data including temperature readings, HVAC control states, learned patterns, and performance metrics. This document details the thermostat-specific data structures and management.

## Temperature Data

### Current Temperature Readings
Real-time temperature data from multiple sensors with calibration and filtering.

```c
// Temperature data structure
typedef struct {
    float current_temperature;   // Current temperature reading
    float target_temperature;    // Target setpoint temperature
    float outdoor_temperature;   // Outdoor temperature (if available)
    float humidity;              // Current humidity reading
    timestamp_t last_update;     // Last sensor update time
    sensor_status_t status;      // Sensor status
    calibration_data_t calibration; // Calibration data
} temperature_data_t;

// Temperature history for learning
typedef struct {
    timestamp_t timestamp;       // Reading timestamp
    float temperature;           // Temperature value
    float humidity;              // Humidity value
    bool occupancy;              // Occupancy state
    hvac_mode_t mode;            // HVAC mode at time of reading
    user_action_t user_action;   // User action (if any)
} temperature_history_point_t;
```

## HVAC Control Data

### Control State Data
Current HVAC system state and control parameters.

```c
// HVAC control state
typedef struct {
    hvac_mode_t mode;            // Current HVAC mode
    hvac_state_t state;          // Current HVAC state
    fan_state_t fan_state;       // Fan control state
    float heat_setpoint;         // Heating setpoint
    float cool_setpoint;         // Cooling setpoint
    float deadband_heat;         // Heating deadband
    float deadband_cool;         // Cooling deadband
    timestamp_t last_change;     // Last state change time
    control_output_t outputs;    // Control output values
} hvac_control_data_t;

// Control outputs
typedef struct {
    bool heat_relay;             // Heat relay state
    bool cool_relay;             // Cool relay state
    bool fan_relay;              // Fan relay state
    bool aux_heat_relay;         // Auxiliary heat relay
    float modulation_level;      // Modulation level (0-100%)
    timestamp_t last_update;     // Last output update
} control_output_t;
```

### PID Control Data
PID controller parameters and state for temperature control.

```c
// PID controller data
typedef struct {
    float kp;                    // Proportional gain
    float ki;                    // Integral gain
    float kd;                    // Derivative gain
    float integral;              // Integral accumulator
    float prev_error;            // Previous error
    float output_min;            // Minimum output limit
    float output_max;            // Maximum output limit
    timestamp_t last_update;     // Last control update
    performance_metrics_t metrics; // Control performance
} pid_control_data_t;

// Control performance metrics
typedef struct {
    float steady_state_error;    // Steady state error
    float settling_time;         // Settling time in seconds
    float overshoot;             // Maximum overshoot
    float stability_index;       // Stability index
    int oscillations;            // Number of oscillations
} performance_metrics_t;
```

## Schedule Data

### Temperature Schedule
Time-based temperature scheduling with day-specific programs.

```c
// Schedule data structure
typedef struct {
    bool enabled;                // Schedule enabled flag
    bool auto_schedule;          // Auto-schedule learning enabled
    schedule_day_t days[7];      // Daily schedule data
    away_settings_t away;        // Away mode settings
    vacation_settings_t vacation; // Vacation settings
    schedule_stats_t stats;      // Schedule statistics
} schedule_data_t;

// Daily schedule
typedef struct {
    day_of_week_t day;           // Day of week
    schedule_entry_t heat_entries[MAX_ENTRIES]; // Heat schedule
    schedule_entry_t cool_entries[MAX_ENTRIES]; // Cool schedule
    int heat_count;              // Number of heat entries
    int cool_count;              // Number of cool entries
} schedule_day_t;

// Schedule entry
typedef struct {
    time_of_day_t time;          // Time of day
    float temperature;           // Target temperature
    schedule_mode_t mode;        // Schedule mode
    bool active;                 // Entry active flag
} schedule_entry_t;
```

## Learning Data

### User Pattern Learning
Machine learning data for user behavior patterns and preferences.

```c
// Learning data structure
typedef struct {
    learning_model_t model;      // Learning model
    pattern_data_t patterns;     // Learned patterns
    user_preferences_t prefs;    // Learned preferences
    adaptation_data_t adaptation; // Adaptation data
    learning_stats_t stats;      // Learning statistics
} learning_data_t;

// Learning model
typedef struct {
    model_type_t type;           // Model type (neural network, decision tree)
    float accuracy;              // Model accuracy
    timestamp_t last_trained;    // Last training timestamp
    int training_iterations;     // Number of training iterations
    model_parameters_t params;   // Model parameters
} learning_model_t;

// User patterns
typedef struct {
    time_pattern_t time_patterns[MAX_PATTERNS]; // Time-based patterns
    temperature_pattern_t temp_patterns[MAX_PATTERNS]; // Temperature patterns
    occupancy_pattern_t occupancy_patterns[MAX_PATTERNS]; // Occupancy patterns
    int pattern_count;           // Number of learned patterns
    float confidence;            // Pattern confidence level
} pattern_data_t;
```
