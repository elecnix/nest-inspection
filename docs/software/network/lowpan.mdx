# Low-Power Wireless (802.15.4)

The Nest Learning Thermostat implements IEEE 802.15.4 low-power wireless communication as the foundation for Zigbee networking and other low-power wireless protocols. This provides reliable, low-power communication for smart home devices and sensor networks.

## IEEE 802.15.4 Overview

### Physical Layer Characteristics
- **Frequency**: 2.4GHz ISM band (primary), 868/915MHz (optional)
- **Data Rate**: 250kbps at 2.4GHz, 20/40kbps at sub-GHz
- **Modulation**: O-QPSK with DSSS (Direct Sequence Spread Spectrum)
- **Channel Spacing**: 5MHz channel spacing at 2.4GHz
- **Range**: 10-100m indoor, up to 1km line-of-sight

### Channel Allocation
| Band | Frequency Range | Channels | Data Rate |
|------|------------------|----------|-----------|
| 2.4GHz | 2405-2480MHz | 11-26 (16 channels) | 250kbps |
| 915MHz | 902-928MHz | 1-10 (10 channels) | 40kbps |
| 868MHz | 868-868.6MHz | 0 (1 channel) | 20kbps |

## Radio Hardware

### Radio Module Specifications
- **Chipset**: TI CC253x series or similar
- **Output Power**: +4.5dBm maximum (adjustable)
- **Receiver Sensitivity**: -97dBm typical
- **Antenna**: Internal PCB antenna or external connector
- **Interface**: SPI or UART to host processor

### RF Performance
- **Adjacent Channel Rejection**: 30dB typical
- **Alternate Channel Rejection**: 45dB typical
- **Blocker Performance**: >0dBm at 3MHz offset
- **Frequency Accuracy**: ±40ppm
- **Phase Noise**: -90dBc/Hz at 1MHz offset

## MAC Layer Features

### MAC Capabilities
- **CSMA/CA**: Carrier Sense Multiple Access with Collision Avoidance
- **ACK**: Optional acknowledgments for reliability
- **RTS/CTS**: Request to Send/Clear to Send for hidden nodes
- **Beacon**: Beacon-enabled networks for synchronization
- **Security**: AES-128 encryption at MAC layer

### Frame Types
- **Beacon Frame**: Network synchronization and information
- **Data Frame**: Data transmission between devices
- **ACK Frame**: Acknowledgment of received frames
- **Command Frame**: Network control and management commands
- **Beacon Request**: Beacon request for network discovery

### Frame Structure
```
+--------+--------+--------+--------+--------+--------+--------+
| Preamble | SFD | Frame Length | Frame Control | Sequence Number |
+--------+--------+--------+--------+--------+--------+--------+
| Addressing Fields | Payload | FCS |
+--------+--------+--------+--------+--------+
```

## Network Topologies

### Star Topology
- **Coordinator**: Central network coordinator
- **End Devices**: Direct communication with coordinator
- **Range**: Limited to coordinator's radio range
- **Power**: Low power consumption for end devices
- **Use Case**: Simple sensor networks

### Peer-to-Peer Topology
- **Direct Communication**: Devices communicate directly
- **No Coordinator**: No central coordinator required
- **Range**: Limited to direct radio range
- **Flexibility**: Flexible network formation
- **Use Case**: Simple device-to-device communication

### Mesh Topology (with Zigbee)
- **Multi-hop**: Data can hop through multiple nodes
- **Self-healing**: Automatic route repair
- **Extended Range**: Network range beyond single hop
- **Complexity**: More complex network management
- **Use Case**: Large-scale smart home networks

## Power Management

### Power Saving Modes
- **Active Mode**: Radio always on for communication
- **Idle Mode**: Radio on but not transmitting
- **Sleep Mode**: Radio powered down for power saving
- **Deep Sleep**: Maximum power saving mode

### Power Consumption
| Mode | Current Consumption | Description |
|------|---------------------|-------------|
| Transmit | 25mA | Data transmission |
| Receive | 25mA | Data reception |
| Idle | 1mA | Radio idle, ready to receive |
| Sleep | 1μA | Radio powered down |

## Security Features

### AES-128 Encryption
- **Encryption**: AES-128 block cipher
- **Key Management**: Secure key distribution
- **Authentication**: Message authentication codes
- **Integrity**: Data integrity protection

### Security Modes
- **No Security**: No encryption or authentication
- **AES-CTR**: Counter mode encryption
- **AES-CBC-MAC**: Cipher block chaining with MAC
- **AES-CCM**: Counter with CBC-MAC mode

### Security Configuration
