# User Interface

The Nest Learning Thermostat features a sophisticated circular touch-and-turn interface with a high-resolution color display. The UI is rendered by the `nlclient` application and supports 9 languages with extensive localization.

## Hardware Interface

### Display
- **Type**: OMAP framebuffer-based color display
- **Interaction**: Rotary encoder ring + push button
- **Brightness**: Auto-adjusting based on ambient light sensor
  - **Levels**: Dark Room (130), Low (42), Medium (90), High (100), Dark (40)
  - **Auto Mode**: Maps illuminance (0-24025 lux) to brightness (40-100%)

### Input Methods
- **Turn**: Rotate the outer ring to navigate and adjust values
- **Push**: Press the ring to select/confirm
- **Farsight**: Motion detection triggers display from across the room

### Display Modes

#### Main Temperature Display
Shows current temperature with contextual information:
- Current temperature (large, centered)
- Target temperature (when heating/cooling)
- System status indicators
- Time-to-temperature estimates
- Mode indicators (HEAT, COOL, HEAT • COOL, ECO, OFF)

#### Status Indicators
- `HEATING` / `COOLING` - Active HVAC operation
- `HEAT STAGE 2` / `COOL STAGE 2` - Multi-stage operation
- `AUX. HEAT` / `EMERGENCY HEAT` - Auxiliary heating
- `AIRWAVE` - Energy-saving cooling mode
- `COOL TO DRY` - Dehumidification mode
- `PRECOOLING` / `PREHEATING` - Early-on optimization
- `RUSH HOUR` - Demand response event
- `TIME OF SAVINGS` - Time-of-use rate optimization
- `SAFETY` - Safety temperature active
- `SYSTEM ISSUE` - Equipment problem detected

#### Time Estimates
- `IN X MIN` - Time until target temperature
- `IN 1 HR` / `IN 1 HR X MIN` - Longer estimates
- `IN 1½ HR` / `IN 2+ HR` - Extended estimates
- `UNDER 10 MIN` - Nearly ready
- `DELAYED FOR X:XX` - Compressor lockout delay

### Localization Files
- **Location**: `/nestlabs/share/client/locales/`
- **Format**: Apple `.strings` format in `.lproj` directories
- **Size**: 1,716 strings in English locale
- **Structure**: Key-value pairs with context identifiers

Example string keys:
```
"templayer.heating" = "HEATING"
"templayer.cooling" = "COOLING"
"templayer.heatto" = "HEAT TO"
"templayer.coolto" = "COOL TO"
```

## Smart Features

### Auto-Away
Occupancy detection using:
- PIR motion sensor
- Activity patterns
- Schedule learning
- Multi-thermostat coordination

States:
- **Home**: Normal operation
- **Away**: Eco Temperatures active
- **Auto**: System decides based on sensors

### Auto-Schedule
Learning algorithm creates schedule from:
- Manual temperature changes
- Time of day patterns
- Occupancy detection
- Seasonal adjustments

Learning states:
- **Learning**: Building schedule (first week)
- **Ready**: Schedule established
- **Off**: Manual schedule only

### Sunlight Correction
Compensates for direct sunlight on thermostat:
- Detects temperature sensor bias
- Adjusts target temperature
- Prevents overcooling/overheating
- Uses ambient light sensor data

### True Radiant
Optimization for radiant heating systems:
- Early-on timing
- Temperature modulation
- Reduced temperature swings
- OpenTherm integration

### Airwave
AC energy savings feature:
- Turns off compressor early
- Continues fan to extract cooling
- Monitors humidity levels
- Displays savings achieved

**File**: `/nestlabs/share/client/calibration/calibration.plist`

6LoWPAN radio configuration:
- **Format**: 6lowpan-silabs

- **Power Levels**: Region-specific (US/CA vs EU/ROW)
- **Defaults**: Fallback calibration values

## User Workflows

### Daily Use
1. Approach thermostat (Farsight activates)
2. View current temperature and status
3. Turn ring to adjust temperature
4. Push to confirm
5. Display shows time-to-temperature

### Schedule Adjustment
1. Press ring → Select "Schedule"
2. Choose day
3. Select time slot
4. Turn to adjust temperature
5. Push to save

### Equipment Test
1. Press ring → "Settings" → "Equipment" → "Test"
2. Select component to test
3. Confirm test start
4. Observe system operation
5. Confirm test completion

### Wi-Fi Setup
1. Press ring → "Settings" → "Network" → "Wi-Fi"
2. Select network from list
3. Enter password using encoder wheel
4. Confirm connection
5. Wait for "Thermostat is online"

## Error Messages

### Common Errors
- **E1-E99**: Wiring errors with specific codes
- **N1-N9**: Wiring notes/warnings
- **No Power**: Power wire issues
- **Invalid Entry Key**: Heat Link pairing failed
- **Wrong PIN**: Temperature lock code incorrect
- **Can't Connect**: Network connection failed

### Error Resolution
Each error includes:
- **Description**: What the problem is
- **Learn More**: Link to nest.com/eXX
- **Actions**: Troubleshooting steps
- **Pro Contact**: Option to contact installer
