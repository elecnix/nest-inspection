# Nest Learning Thermostat Knowledge Base

Comprehensive documentation for the Nest Learning Thermostat embedded system.

## Data Source

This documentation is based on data exfiltrated from a live Nest Learning Thermostat (Serial: 02AA01AC481302W4) on November 7, 2025. The exfiltrated data includes:

- Complete directory trees from `/media` and `/nestlabs`
- Raw partition images of all 6 MTD flash partitions (196MB total)
- 26+ operational data files (JSON and recovery formats)
- 19 system service binaries
- 22 shared libraries
- Firmware images, localization files, and calibration data

All information has been verified against the actual device and exfiltrated data.

## About This Device

The Nest Learning Thermostat is an embedded Linux-based smart thermostat that combines sophisticated hardware with intelligent software to provide automated climate control.

**Key Specifications:**
- **Operating System**: Linux kernel 3.10.53
- **Architecture**: ARMv7l
- **Device Serial**: 02AA01AC481302W4
- **Total Storage**: 196MB across 6 MTD partitions
  - Root: 46MB (mtdblock9, 58% used)
  - System Config: 4MB (mtdblock10, 11% used)
  - User Config: 8MB (mtdblock11, 7% used)
  - Data: 20MB (mtdblock12, 6% used)
  - Log: 20MB (mtdblock13, 4% used)
  - Scratch: 92MB (mtdblock14, 4% used)
