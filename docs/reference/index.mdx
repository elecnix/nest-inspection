# Filesystem Reference

Complete documentation of every directory and file in the Nest Learning Thermostat filesystem, based on data exfiltrated from a live device.

## Overview

The Nest Thermostat uses a Linux-based filesystem with 6 MTD flash partitions totaling 196MB of storage. This reference documents the complete structure, file-by-file.

## Filesystem Structure

```
/                           # Root filesystem (46MB, read-only)
├── bin/                    # Standard Linux binaries
├── sbin/                   # System binaries
├── lib/                    # System libraries
├── usr/                    # User programs
├── etc/                    # System configuration
│   └── nestlabs/          # Nest-specific configs
├── var/                    # Variable data (tmpfs)
├── tmp/                    # Temporary files (tmpfs)
├── dev/                    # Device files
├── proc/                   # Process information
├── sys/                    # System information
├── nestlabs/              # Nest Labs software → 105+ files
│   ├── bin/               # User binaries (2 files)
│   ├── sbin/              # System daemons (19 files)
│   ├── lib/               # Shared libraries (24 files)
│   └── share/             # Resources (60+ files)
└── media/                 # Mounted partitions → 52+ files
    ├── system-config/     # System settings (7 files)
    ├── user-config/       # User preferences (5 files)
    ├── data/              # Operational data (29 files)
    ├── log/               # System logs (8 files)
    └── scratch/           # Temporary storage (1+ files)
```

## Documentation Sections

### Root Filesystem
[Complete Reference →](/reference/filesystem-root)

Standard Linux filesystem hierarchy with Nest-specific additions:
- `/bin`, `/sbin`, `/lib` - Standard Linux binaries and libraries
- `/etc/nestlabs/` - Nest configuration files
- `/dev` - Device files (MTD partitions, sensors, display)
- `/proc`, `/sys` - Kernel interfaces
- Tmpfs mounts for `/var`, `/tmp`

### Nest Labs Directory
[Complete Reference →](/reference/nestlabs)

All Nest-proprietary software (105+ files):
- **2 binaries** - wirelessregcal, zb-loader
- **19 daemons** - nlclient, osm, watchdogd, updaters, etc.
- **24 libraries** - System, network, Weave protocol, utilities
- **60+ resources** - Firmware, fonts, locales, images, calibration

## File Formats

### Binary Recovery Files (.recovery)
- Atomic writes with checksums
- Power-loss protection
- Used for critical state
- Examples: schedulemanager, autoaway, energystats

### JSON Files (.json)
- Human-readable configuration
- Standard JSON format
- Used for non-critical settings
- Examples: rateplan, smartthermostatmanager

### XML Files (.xml, .config)
- Configuration files
- User settings
- Example: settings.config

### Binary Calibration (.bin)
- Hardware calibration data
- Device-specific
- Examples: wl12xx-nvs.bin

### Property Lists (.plist)
- Apple-style configuration
- Firmware metadata
- Examples: nlbpfirmware.plist

### Log Files
- Text format
- Syslog-style or structured
- Rotated when size limits reached

## Data Persistence

### Critical Data
- Stored in `.recovery` files
- Atomic writes, checksums
- Backed up to cloud
- Examples: schedules, auto-away, energy stats

### Configuration
- Stored in JSON/XML
- Can be regenerated
- Backed up to cloud
- Examples: rate plans, user settings

### Logs
- Text files
- Rotated and uploaded
- Can be deleted
- Examples: messages, nlclient

### Temporary
- Scratch partition
- Not backed up
- Can be cleared
- Examples: dropbox queue, crash dumps
