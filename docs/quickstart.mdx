# Quick Start Guide

Get up and running with Nest Thermostat development and documentation in minutes.

## Documentation Development

### Prerequisites
- Node.js 18+ and npm

### Local Development

```bash
cd docs
npm install
npm run dev
```

This will start the Mintlify development server at `http://localhost:3000`.

### Building

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Device Access

### Prerequisites

- Network access to the Nest Thermostat device
- SSH client installed on your system
- Basic understanding of Linux systems

## First Steps

### 1. Verify System Status

```bash
# Check running processes
ps aux

# View system information
uname -a

# Check disk usage
df -h
```

### 2. Explore Key Directories

```bash
# Nest Labs software
ls -la /nestlabs

# Configuration files
ls -la /etc/nestlabs

# Thermostat data
ls -la /media/data

# System logs
ls -la /media/log
```

### 3. Monitor System Activity

```bash
# View system logs
tail -f /media/log/messages

# Monitor nlclient activity
tail -f /media/log/nlclient
```
